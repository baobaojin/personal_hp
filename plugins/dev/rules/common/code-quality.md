# 代码质量规范

## 代码组织

- 高内聚，低耦合，单一职责
- 一个文件不超过 300 行
- 重复 3 次以上的代码抽取成函数

## 错误处理

- API 请求、用户输入验证、文件上传、网络问题都必须处理
- 禁止空的 catch 块
- 错误信息要有上下文，面向用户不暴露技术栈细节

## 性能考虑

- 不在 render 中创建函数或对象
- 不过度使用 Context 和全局状态
- 图片懒加载，大列表虚拟滚动

## 可维护性

- 变量名要有意义，避免魔法数字（提取为常量）
- 复杂逻辑添加注释说明"为什么"
- 关键功能必须有测试
