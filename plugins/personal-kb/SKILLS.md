# personal-kb Skill 目录

> 完整的 Skill 和工作流列表，包含触发词和使用场景。
> 安装后直接用自然语言触发，Claude Code 会自动识别。

---

## 基础 Skill

### intake — 内容录入

**文件**：`skills/intake.md`

把学到的、看到的、想到的内容整理成规范笔记存入知识库。自动生成 frontmatter、判断目录、设置复习时间。

**触发词**：记录、记一下、我刚学了、我想到了、帮我整理一下

---

### ask — 知识问答

**文件**：`skills/ask.md`

基于个人知识库回答问题。明确区分"你的笔记记录"和"通用知识"，不编造个人记录。

**触发词**：帮我回答、我记得、查一下、我之前学过、根据我的笔记

---

### review — 复习出题

**文件**：`skills/review.md`

扫描今天到期的笔记，逐篇出题。答对推迟 7 天，答错明天再来。

**触发词**：复习、今天该复习什么、出题考我、检测一下

---

### plan — 学习规划

**文件**：`skills/plan.md`

分析当前学习状态，直接给出今天应该做的一件具体的事（不列清单，直接推荐）。

**触发词**：今天学什么、帮我安排、学习计划、这周怎么学

---

### organize — 批量整理

**文件**：`skills/organize.md`

把一批本地文件或文件夹内容整理归类到知识库对应目录。

**触发词**：帮我整理这些文件、归纳这批材料、整理进知识库

---

## 扩展 Skill

### intake-article — 文章整理

**文件**：`skills-extended/intake-article.md`

整理公众号、博客、技术文章到知识库。支持链接抓取、粘贴文本，提炼核心内容而非逐字复制。

**触发词**：帮我整理这篇文章、存一下这篇、帮我总结这篇公众号

---

### intake-book — 图书笔记

**文件**：`skills-extended/intake-book.md`

整理读书笔记到知识库。自动关联书名、作者、章节信息，用书名作为 series 追踪阅读进度。

**触发词**：帮我整理这本书、把这本书的笔记存进来、读书笔记整理

---

### write-guide — 内容写作

**文件**：`skills-extended/write-guide.md`

基于知识库已有记录，生成结构化的攻略、技术总结、经验分享等内容输出。

**触发词**：帮我写攻略、整理XXX攻略、帮我写总结

---

### summarize — 内容总结

**文件**：`skills-extended/summarize.md`

对多份本地文档、公众号链接或粘贴文本进行总结归纳，生成结构化笔记存入知识库。

**触发词**：帮我总结、整理归纳一下、梳理一下、把XXX整理成一篇总结

---

## 工作流

工作流是多个 Skill 的串联，适合有明确起点和终点的完整任务。

### learning-workflow — 学习工作流

**文件**：`workflows/learning-workflow.md`

系统学习一个新方向的完整闭环：

```
建知识地图 → 制定学习计划 → 每次学完记录 → 定期复习 → 阶段复盘
```

**触发词**：我要开始学XXX、帮我规划XXX的学习、系统学习XXX

---

### dev-workflow — 开发工作流

**文件**：`workflows/dev-workflow.md`

做一个具体开发任务的完整闭环：

```
任务规格 → 拆解步骤 → 逐步执行 → 经验沉淀 → 归档总结
```

**触发词**：我要做XXX功能、帮我拆解这个任务、开发任务

---

## 快速对照

| 场景 | 用哪个 |
|---|---|
| 随手记一个知识点 | `intake` |

| 整理一章读书笔记 | `intake-book` |
| 汇总多份资料 | `summarize` |
| 查询知识库内容 | `ask` |
| 今天该复习什么 | `review` |
| 今天该学什么 | `plan` |
| 系统学一个新方向 | `learning-workflow` |
| 做一个开发任务 | `dev-workflow` |
| 写旅游攻略/技术总结 | `write-guide` |
| 批量整理本地文件 | `organize` |
