# 日志

时间线记录：daily note、周复盘、月复盘。

## 推荐结构

```
journal/
├── daily/      # 每日记录（YYYY-MM-DD.md）
├── weekly/     # 周复盘
└── monthly/    # 月复盘
```

## Daily Note 模板

```markdown
---
title: YYYY-MM-DD
category: journal
tags: [daily]
status: active
created: YYYY-MM-DD
updated: YYYY-MM-DD
---

## 今天做了什么

## 学到了什么

## 遇到了什么问题

## 明天计划
```
