## 适用场景

开始系统学习一个新方向，例如：
- "我要开始学 LangGraph"
- "帮我规划 Java 并发的学习路线"
- "我想系统学一下 RAG"

## 工作流步骤

### Step 1：/map — 建知识地图

- 在 `docs/meta/maps/` 下创建或更新该方向的知识地图文件
- 和用户确认当前水平，拆分三个状态：
  - 已掌握：已经熟练的内容
  - 学习中：当前在学的内容
  - 待学：计划学但还没开始
- 保存知识地图文件

### Step 2：/plan-learning — 制定学习计划

- 把"待学"拆成有序的知识点列表
- 每个知识点对应未来的一篇笔记
- 设置 series 名称（如：langraph-basics）和每个知识点的 series_order
- 第一个任务：今天就能开始，≤ 30 分钟

输出格式：
```
学习路线：<方向名>
系列标识：<series 名>

1. [知识点名] - 预计 XX 分钟
2. [知识点名] - 预计 XX 分钟
...

今天从第 1 个开始：[具体怎么开始]
```

### Step 3：/intake（每次学完循环执行）

- 每学完一个知识点，调用 intake Skill 记录笔记
- 填写 series 和 series_order
- 设置 next_review（默认 7 天后）
- 更新知识地图：把该知识点从"待学"移到"学习中"

### Step 4：/review（每日定期执行）

- 每天运行 review Skill
- 到期笔记出题复习
- 答错的知识点重点关注

### Step 5：/recap — 阶段复盘

**触发时机**：知识地图"学习中"的内容全部完成后

步骤：
- 回顾整个学习过程，总结掌握情况
- 把"学习中"内容更新为"已掌握"（确实掌握的）
- 识别还有哪些薄弱点，补充到"待学"
- 在 `docs/journal/` 写一篇复盘笔记

## 完成判断

- [ ] 知识地图"学习中"已清空
- [ ] 每个知识点都有对应的笔记文件
- [ ] 复盘笔记已写入 journal/
